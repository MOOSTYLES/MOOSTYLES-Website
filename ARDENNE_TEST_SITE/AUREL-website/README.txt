AUREL — Complete Updated Website Source

Extract the ZIP and open index.html for the homepage or listings.html for the sales listing page. No installation or build step is required.

FILES
index.html, style.css, app.js — Original homepage and its interactions.
listings.html — Sales listing page structure.
listings.css — Sales page styles and responsive layouts.
listings.js — Inventory, filters, sorting, listing details and inquiry downloads.
assets/ — All website images.

EDITING INVENTORY
Edit the inventory array at the beginning of listings.js to update names, prices, descriptions, specifications and locations. The current listings and prices are illustrative samples, not live offers. Images are generated concepts. Replace these with accurate inventory and authorized photography before using the site to sell real items. Update category counts in listings.html when changing the number of listings.

INQUIRIES
The current inquiry action downloads a text brief; it does not send messages to a seller. Seller contact and a backend are not connected.

HOSTING
Upload all HTML, CSS, JavaScript and assets together to a static web host. Google Fonts needs an internet connection; system fonts act as fallbacks.

This package contains the complete updated website source and assets. Hosting credentials and internal deployment metadata are excluded.
