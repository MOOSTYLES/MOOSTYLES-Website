# Publishing on the Blog

Open `/admin/`, sign in as usual, and choose **Blog Posts**. Edit the starter draft or create a new post.

1. Add a title, a stable URL slug and a short summary.
2. Choose Announcement, Blog, Tutorial, Update, Behind the Scenes or Community. Add any topic tags you want visitors to filter by.
3. Upload a cover image and describe it in Cover Image Description. Use the content editor to write the full post and upload inline images. Headings, links, numbered steps, bullet lists, quotes, tables and code are supported.
4. Set the publication date and author. Enable Featured Post to place it in the spotlight; the newest featured post takes priority.
5. Keep Visibility set to Draft while working. When ready, set it to Published and complete the dashboard's editorial publishing workflow. The post appears after the existing site deployment finishes.

Saving a draft does not make it public. Drafts are excluded from listings, article routes, search and the sitemap. Publication dates control ordering and display, not automatic scheduling. To hide a live post, change Visibility to Draft and publish that change.

Posts live at `/blog/your-slug`; images are uploaded under `/projects/Blog/your-slug/`. Keep the slug stable to preserve links. The public site starts with an empty Blog; its example post is a draft.
